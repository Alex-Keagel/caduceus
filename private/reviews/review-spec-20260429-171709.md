## Findings

### 🔴 Critical
1. **[spec-orchestrator-status-snapshot.md:687-702]** Clause-(d) is still unimplementable as written: detection defines only a replay index `(stream_seq -> fingerprint)`, but action requires replaying exact `SnapshotDelta` payloads. No normative payload store exists. **Fix:** Replace the detection paragraph with: “Detection uses two co-indexed bounded structures owned by the daemon: (1) a replay index `(stream_seq -> snapshot_fingerprint)` and (2) a replay buffer `(stream_seq -> SnapshotDelta)`. They MUST be populated atomically on each delta emission and trimmed together. Clause (d) is eligible only if both structures contain every `stream_seq` needed for `(s_c, current_stream_seq]`; otherwise the daemon MUST emit `Resync`.”
2. **[spec-orchestrator-status-snapshot.md:492-500, 698-705, 1789-1793]** Replay ordering is still not provable. The subscriber is attached to the live broadcast channel before the ack is emitted, so live deltas can overtake buffered replay unless the daemon explicitly gates them. **Fix:** Add to clause-(d) daemon action: “For clause (d), the daemon MUST place the subscriber in replay mode. While replay mode is active, live broadcast deltas with `stream_seq > current_stream_seq_at_ack` for that subscriber MUST be buffered and MUST NOT be forwarded until replay `(s_c, current_stream_seq_at_ack]` drains. Delivery order to that subscriber MUST be: `SubscribeAck`, then contiguous replay `s_c+1 .. current_stream_seq_at_ack`, then buffered live deltas in ascending `stream_seq` order. If the daemon cannot enforce this ordering, it MUST emit `Resync` instead.”
3. **[spec-orchestrator-status-snapshot.md:726-735, 747-750]** Z-8 is still too weak to justify `s_c absent => (a)/(P)`. “Retained span >= recent_history_ring_size” does not define `ring_oldest_seq` and does not require dense retention. Holes inside the span still break the proof. **Fix:** Replace Z-8 with: “`ring_oldest_seq` is the smallest `stream_seq` retained in the replay index/buffer pair. Invariant Z-8: retention is dense — for every integer `q` with `ring_oldest_seq <= q <= current_stream_seq`, both the replay index and replay buffer contain entry `q`. Clause (P) fires iff `since_stream_seq < ring_oldest_seq`; otherwise `s_c` lookup MUST succeed.”

2. Add per-subscriber replay-mode gating so live deltas cannot overtake replay.
3. Strengthen Z-8 / define `ring_oldest_seq` normatively.
4. Fix T-7, T-10 inventory mapping, and the WorkspaceStatus cross-spec reference.
