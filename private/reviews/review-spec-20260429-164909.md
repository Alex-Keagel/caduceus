## Findings

### 🔴 Critical
1. [Line 431-470] — Handshake capability parsing is not fail-closed; a valid JSON `handshake` with garbage `payload.capabilities` can crash `parse_capabilities` or partially mutate session state. **Fix:** replace handshake parsing with an explicit `match parse_capabilities(...)` block that only assigns `runner.capabilities` after validation succeeds and emits `protocol_violation(reason = "invalid_handshake_capabilities")` + `stop_cascade(...)` on error.
2. [Line 1310-1312] — `reconcile_tokens` never validates mode or component domains before arithmetic; malformed or negative values can underflow or corrupt totals. **Fix:** validate `mode` and every token field before reading `stored`; reject invalid payloads with `protocol_violation(reason = "invalid_token_update")` and stop the session.

### 🟡 Important
1. [Line 89] — Concurrent-run isolation is implicit, not normative. **Fix:** state that all per-attempt mutable state is runner-local and any daemon-wide maps must be keyed by `run_id` / attempt identity.
2. [Line 1540-1547, 1656-1660] — `SessionMismatch` is optional in v1, so the error matrix is not actually contractible. **Fix:** require synchronous session validation before replying to reattach and make `SessionMismatch` normative in v1.
3. [Line 1840-1849] — Broker peer auth uses UID + PID lineage but not process start-time binding, leaving PID reuse ambiguity. **Fix:** require recorded spawn-time / creation-time checks for every PID consulted in the lineage.
4. [Line 1514, 2257-2284] — Cross-references are incomplete and one internal reference dangles. **Fix:** remove `§4.6.1` from the `boot_id` comment and add explicit entries for spec #4, spec #5, and spec #8 in §9.

### 🟢 Suggestions
1. [Line 1247-1253] — Missing-handshake fallback is restated instead of referenced, increasing drift risk. **Fix:** collapse this paragraph to one canonical cross-reference back to §3.2 + T-4.

## Recommended Actions
1. Make handshake parsing fail-closed and side-effect-free until validated.
2. Add token payload domain validation before any arithmetic or watermark logic.
3. Make concurrent-run state ownership explicit.
4. Make reattach synchronous and deterministic for every listed variant.
5. Fix dangling references and deduplicate fallback language.
