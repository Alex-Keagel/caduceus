Line 944 says clause (b) is reachable when `since_boot_id != Some(daemon.boot_id)`, which includes `None`; but §3.4 explicitly says `since_boot_id == None` cannot take clause (b)'s explicit-inequality path and instead follows clause (a)/(c)/(d)/(d′) logic. **Fix:** change the boot bullet to explicit mismatch only: `(b) — boot mismatch (since_boot_id = Some(other) && other != daemon.boot_id)` and state that any trigger referencing `ring_oldest_seq` is unsatisfied when the replay index is empty.
2. [spec-orchestrator-status-snapshot.md:121, 883-889, 2293-2352] — `RingEviction` and `LockStepTrimRace` are not mechanically disjoint.
